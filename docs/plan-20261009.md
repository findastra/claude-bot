# Plan: Claude Bot v0

Written by Claude Opus 5.5 (claude-opus-5-5), 2026-10-09. Every item is a plan, not a fact
about working code.

## What it does (feature parity with the Codex/ChatGPT "Mini")
| Feature | v0 |
| --- | --- |
| Small always-on-top window, draggable, remembers its position | yes |
| Orange face that shows the Cage's nine moods (idle, curious while working, happy when done, sick when a key is missing) | yes |
| Global shortcut opens a quick-chat box | yes (default `Ctrl+Alt+Space`) |
| Status bubble with progress of chats started here | yes |
| Bell with unread updates | yes |
| Click the face to open Claude | yes (opens the Claude desktop app or claude.ai) |
| Hide without cancelling work | yes |
| Status of chats running inside the Claude desktop app | no: no public interface; see README Limits |

## Look
Original. An orange face in the house pixel style (black one-pixel outline, dot eyes with one
white highlight, pink cheeks). Mood symbols come from the Cage's shared sticker set. **Do not
copy OpenAI's artwork, icons, layout or wording**, per the Cage's AGENTS.md.

## Stack (house pattern)
Like the Desktop Farmer (`astras-pet-apps/docs/farmer-dock-20261008.md`): a C# WinForms app
compiled by the .NET Framework compiler that ships with Windows. A `start-*.cmd` builds and runs
it, with no packages to install.

## Quick chat
Calls the Claude API (Messages API, streamed) with Astra's own API key.
- The key is read from the Windows user environment variable `ANTHROPIC_API_KEY`, or from a file
  outside the repo. It is never committed or logged. API Fairy keeps notes about the key, not
  the key itself.
- No key means the `sick` mood, with words saying what is needed and how to add it.
- Chat history stays on the PC.
