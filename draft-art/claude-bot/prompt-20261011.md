# Claude Bot art draft

Original design for Astra, generated with the built-in imagegen tool by OpenAI Codex (GPT-6), 2026-10-11. No paid API or CLI was used. This is a draft awaiting owner review, and is not wired into the live app.

## Exact prompt

Create an ORIGINAL cute orange-faced floating desktop assistant called Claude Bot for Astra's pet apps. This is original character design, not any company's existing mascot: no logos, asterisks, spider or crab shapes. A simple rounded-square robot head with a warm tangerine-orange face, a narrow pale-cream casing border, two small dark burgundy rounded side tabs, a tiny cream antenna tipped burgundy, two tiny navy feet. No torso, no arms, no props. Dot black eyes with one white highlight each, small cheerful mouth and pale peach cheek blush. Distinctive orange/cream/burgundy palette. Produce a3-by-3 grid sprite sheet of the EXACT SAME fine pixel-art character nine times. Each sprite roughly80pixels tall, polished SNES detail, flat crisp colored pixel blocks, solid thin BLACK outline, no antialiasing no gradient no soft3D. Identical face size/body/casing/pose/palette/scale throughout. Nine expressions rowmajor: calm neutral open eyes, blink both eyes closed, big happy smile, curious via slightly raised eyebrow and small round mouth (both eyes identical to idle), worried, sad, tired/unwell, shocked wide eyes, asleep. Keep both eyes symmetric, small with white highlights when open. Transparent background and generous equal gutters between all nine whole characters. No cell borders, no labels, no numbers, no text, no punctuation symbols, no sweat drops tears bandages or Zs. Actual RGBA transparency. Draft game sprite assets ready for slicing.

## Conversion

The transparent 3x3 sheet was sliced with the hub's scripts/build-desktop-art-20261011.mjs into nine 256px frames using a shared scale and original alpha. No mood stickers were generated. The neutral frame is the proposed app icon. Original source sheet is retained.
